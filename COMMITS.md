# List of prefixes for commit messages

The goal is to create the smallest possible commits with a single context

Prefixes can be mixed like this :  
`[feat+db] new feature including database migration`

---

## Tags

### [code]

> Simple add or edit in code

### [code:cmd] / [cmd]

> Command related changes

### [code:feat] / [feat]

> New feature added to the project

### [code:fix] / [fix]

> Bug correction

### [code:refactor] / [refactor]

> Rework the code without adding new feature

### [conf]

> Config related changes

### [cs]

> Upgrade code for Coding Style (php-cs-fixer, phpstan, ...) suffixed with #FIXER

### [db]

> Database related changes

### [db:seed] / [seed]

> Fixtures related changes

### [doc]

> Update documentation

### [front]

> Front-end related changes

### [libs]

> Install / Update libraries

### [test]

> Unit Test related changes

### [trans]

> Edit translation in the project
